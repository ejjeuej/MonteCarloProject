# Monte Carlo Methods and Scientific Computing

A collection of Monte Carlo simulations demonstrating how microscopic random processes give rise to macroscopic deterministic laws.

This project explores the connections between:

* Random Walks
* Diffusion Processes
* Laplace Equation
* Monte Carlo Numerical Methods
* Electrostatics
* Quantitative Finance

## Topics Covered

### Random Walks and Diffusion

* 1D random walk simulation
* 2D random walk simulation
* Mean squared displacement (MSD)
* Verification of diffusion laws
* Boundary condition effects

### Monte Carlo Solution of PDEs

* Laplace equation
* Dirichlet boundary conditions
* Random walk interpretation of harmonic functions
* Comparison with finite difference methods

### Applications

* Electrostatic potential simulation
* Electric field visualization
* European option pricing under geometric Brownian motion
